## Selected Work at Airix360

<p align="left">
  <a href="https://github.com/Airix360">
    <img src="https://img.shields.io/badge/GitHub-Airix360-181717?style=for-the-badge&logo=github&logoColor=white" alt="Airix360 on GitHub" />
  </a>
</p>

The **Airix360** GitHub organisation is where I build and maintain publishing
technology, payment infrastructure, editorial tooling, identity systems, and
journal-operation software for Airix Media and the wider scholarly-publishing
ecosystem.

| Repository | What it does |
|---|---|
| [**Contributor User Sync**](https://github.com/Airix360/contributorUserSync) | Connects OJS submission contributors to real user accounts, reuses verified ORCID iDs, and gives editors sync, invite, notification, and bulk-reporting tools. |
| [**PaystackOJS**](https://github.com/Airix360/PaystackOJS) | Adds secure Paystack payments to OJS for article and issue purchases, subscriptions, and publication fees, with server-side verification, receipts, refunds, and webhook protection. |
| [**OJS Magic Login**](https://github.com/Airix360/ojs-magic-login) | Adds passwordless OJS sign-in through secure, single-use email links while keeping the standard login flow available. |
| [**Submission Fee for OJS**](https://github.com/Airix360/submissionFee-OJS) | Adds submission-time fees to OJS through its native payment system without modifying or forking OJS core. |
| [**OJS MultiPay**](https://github.com/Airix360/ojs-multipay) | Orchestrates multiple OJS payment gateways with currency-aware routing, gateway suggestions, refunds, disputes, receipts, and a unified payment-management experience. |
